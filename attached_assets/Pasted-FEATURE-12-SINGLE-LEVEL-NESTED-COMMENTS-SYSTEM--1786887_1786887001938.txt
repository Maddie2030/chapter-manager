FEATURE 12: SINGLE-LEVEL NESTED COMMENTS SYSTEM
Description:
High-performance comment section supporting top-level posts and nested replies.

Technical Workflow & API Data Pipeline:

Client calls GET /api/v1/social/comments?seriesId={id}.

The Social Service queries MongoDB. MongoDB's indexing on parent_id allows rapid structural retrieval of thread hierarchies.

React flattens and groups the array: Top-level comments (parent_id: null) are rendered first; child comments are attached directly beneath their respective parents.

JWT validation in the API Gateway ensures users can only delete comments matching their own user_id claim.

Files to Create:
src/components/CommentSection.tsx, src/components/CommentItem.tsx

Prompt for Implementation:

"Create a nested CommentSection component (src/components/CommentSection.tsx). Fetch discussion threads from /api/v1/social/comments. Support top-level posting, single-level nested replies, user avatars, and relative time formatting (e.g., '2 hours ago'). Enforce authentication for posting, and provide author deletion controls."
